# PitchLens 稳定性更新 · 2026-11-20

本次更新处理代码审查中的 4 项 P1 和 4 项 P2。审查基线是 `master` 的 `c3f9085`。

| 优先级 | 问题 | 修改 |
| --- | --- | --- |
| P1 | 已有项目在覆盖保存失败后可能损坏 | 先在目标目录写完临时 ZIP 并刷新到磁盘，再原子替换目标。写入或替换失败时保留旧项目。 |
| P1 | 迟到的识谱结果替换当前乐谱 | 打开或拖入项目、确认手动录入后，先前识谱任务的结果失效。 |
| P1 | 调号、拍号、速度和弧线提示被重算覆盖 | 分开保存识谱诊断和时值校验。项目重开后仍显示待确认提示，可在校正窗口勾选已核对并应用。 |
| P1 | 跟谱跳过谱面休止，正常无声可能丢失位置 | 按当前估计速度推进开头、中间和结尾的休止，连续休止保留各自的时值。 |
| P2 | 识谱超时后关闭窗口可能异常退出 | 关闭请求会停止采集并等待当前识谱线程结束，关闭期间丢弃识谱结果。 |
| P2 | 跨小节延长线被计入上一小节 | 预览提示跨小节延长，并把新小节开头的延长线作为一拍休止，保持上一小节时值。 |
| P2 | 暂停回看只保留约 48 秒 | 保留本次演唱的全部音高曲线，暂停和继续均保留历史。加载乐谱或重置位置会清空曲线。 |
| P2 | 打包失败后仍可能报告成功 | 检查依赖安装和打包的退出码，并验证本次构建产物。Qt 使用系统 ICU，避免构建机上的同名 DLL 造成便携版启动失败。 |

新增回归测试覆盖保存故障、旧项目警告兼容、迟到识谱、关闭时的慢识谱任务、长休止、跨小节延长线和两分钟演唱回看。

## 验证

- Windows 11 x64，Python 3.12.10。Qt 使用离屏模式，启用 `PITCHLENS_REAL_OCR=1` 后执行 `python -m unittest discover -s tests -v`，84 项全部通过。
- 公开带标注示例识别出 24 个音符、8 个小节。音高召回率、音高精确率、时值召回率和小节通过率均为 100%，样本范围为这 1 张自渲染示例。
- 用原生命令替身验证打包脚本。pip 失败、PyInstaller 失败和旧产物三种情况均返回非零，生成新产物时才显示成功。
- 使用 PyInstaller 6.22.3 重新构建 Windows 便携版。运行生成的 `PitchLens.exe`，验证它能打开示例项目，并能从内置示例图片重新识别 24 个音符、显示识谱结果。
- 本轮未使用真实麦克风，也未构建或测试 Inno Setup 安装包。
